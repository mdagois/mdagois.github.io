Sidescroller Level Streaming on the Game Boy

Published on 2026-08-12

This article shows how to stream a level in a sidescrolling game, a bit like Super Mario Land would do. I will assume you have a good grasp of basic Game Boy programming concept, such as vblank, VRAM, tileset, and tilemaps. If you need a refresher, please check my book Game Boy Coding Adventure.

We will start by explaining the graphics data organization we'll use for the streaming system. Then, we see how to compute which data is required in VRAM on any given frame. Finally, we'll see how to copy that data to VRAM, so that the next frame renders correctly.

By the end of the article, you will have a good grasp of the steps required to implement a basic level streaming system on top of which you can add the features required for your game.
